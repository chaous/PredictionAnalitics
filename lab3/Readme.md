# Лабораторная работа №3
## Классификация временных рядов и их прогнозирование на примере метеоданных шести городов России

Двухэтапная система прогнозирования погоды: классификатор климатической зоны → специализированная прогнозная модель для определённого города.

## Задача

Региональный центр гидрометеорологии хочет автоматизированную систему, которая:
1. По куску метеоряда определяет тип климата (один из 6 городов)
2. Применяет специализированную прогнозную модель для этого климата
3. Выдаёт прогноз температуры на 30 дней вперёд

## Данные

Почасовые метеоданные Open-Meteo (реанализ ERA5) за 2019–2025 гг. по 6 городам:

| Город | Климат |
|---|---|
| Москва | Умеренно-континентальный |
| Санкт-Петербург | Умеренно-морской |
| Сочи | Субтропический |
| Геленджик | Субтропический |
| Благовещенск | Резко-континентальный |
| Находка | Муссонный |

**Признаки** (8): temperature_2m, relative_humidity_2m, precipitation, rain, snowfall, weathercode, wind_speed_10m, surface_pressure.

**Объём**: 6 городов × 61 368 часов = 368 208 строк, 0% пропусков.

## Ключевые результаты

### Классификация климата

| Модель | Accuracy | F1-macro |
|---|---|---|
| LogisticRegression | **0.943** | 0.943 |
| LightGBM | 0.930 | 0.930 |
| 1D-CNN | 0.920 | 0.919 |

Логистическая регрессия обогнала сложные модели — качественный feature engineering перевесил сложность модели.

### Прогнозирование температуры на 30 дней (MAE, °C)

| Город | Модель | Модель MAE | Naive MAE | Улучшение |
|---|---|---|---|---|
| Благовещенск | LightGBM | 2.65 | 3.75 | **29.3%** |
| Геленджик | Prophet | 3.10 | 4.26 | 27.2% |
| Москва | AutoARIMA+Fourier | 3.61 | 4.89 | 26.2% |
| Находка | LightGBM | 2.16 | 3.06 | **29.4%** |
| Санкт-Петербург | AutoARIMA+Fourier | 3.10 | 4.13 | 24.9% |
| Сочи | Prophet | 2.54 | 3.54 | 28.2% |

Все специализированные модели обгоняют seasonal naive baseline на 25–30% — сильный результат для месячного прогноза.

## Используемые методы

**Этап 1 — классификация:**
- Извлечение 30 агрегатных признаков из окна (T_mean, T_amplitude, P_total, Snow_h_%, Pr_mean и др.)
- Валидация через GroupKFold по годам (защита от утечки)
- PCA для визуализации разделимости классов
- SHAP и permutation importance для интерпретации

**Этап 2 — прогнозирование:**
- Train: 2019–2023, Val: 2024, Test: 2025
- Baseline: seasonal naive (значение год назад)
- Анализ остатков: тесты Шапиро-Уилка, Льюнга-Бокса, Уайта
- Метрики: MAE, RMSE, MAPE, WAPE, direction accuracy

**Пайплайн:**
- Класс `WeatherPipeline` с методами `predict()`, `save()`, `load()`
- Обработка неопределённости через blending top-2 прогнозов
- Сериализация через joblib

## Технические ограничения

Проект выполнен в Google Colab на CPU, что повлияло на выбор моделей:

- **SARIMA с s=365** нереализуема за разумное время (>30 мин на город) → заменена на AutoARIMA с Fourier-признаками
- **LSTM/Transformer** исключены из-за времени обучения на CPU
- **GNN** отклонены: всего 6 узлов — архитектурно избыточно
